這篇不是給讀者看的，是寫文章時的速查表。每一種格式都示範一次，也順便驗證在手機上不會撐破版面。

標題

用 ## 開二級標題，### 開三級。文章標題已經是一級，內文不要再用 #。

這是三級標題

三級標題會用強調色，適合放在二級標題底下細分。

文字強調

粗體用兩個星號，斜體用一個，刪除線用兩個波浪號。行內程式碼或藥名之類想凸顯的字用反引號包起來，像 topiramate 這樣。

段落中間直接換行不會產生斷行，中文會自動接起來，所以可以放心在編輯器裡折行。想要真正的斷行，在行尾打兩個空白。

清單

無序清單：

  • 第一項

  • 第二項

    • 巢狀的子項目
    • 再一個
  • 第三項

有序清單：

  1. 先問病史
  2. 再做神經學檢查
  3. 最後才決定要不要影像

引用

病人不會照著教科書生病。

引用區塊可以放多個段落，適合放重點提醒或想凸顯的一句話。

長條圖

用 `chart 開一個區塊，每行寫「名稱 | 數值」。捲到這一段時長條會自己長出來，數字會跑上去。

上面的項目名稱與數字都是假的，只用來示範排版。真的要放臨床數據時，記得把 source 換成可查證的出處 —— 讀者不會因為文章標題是「排版參考」就自動認定裡面的數字不能引用。

title、unit、max、source 四個都可以省略。max 省略時會取資料裡的最大值當滿格。

數值

用 `stats 開區塊，每行寫「數值 | 單位 | 說明」。單位可以留空，但分隔線要留著。

42%

說明文字寫在第三欄，可以長一點

18項

單位可以換成任何字

3.5小時

小數會保留一位

關於這些動畫

長條和數字只在第一次捲到時播一次，來回捲動不會重複播放。

數字在原始碼裡就是最終值，動畫只是先歸零再跑上去 —— 所以搜尋引擎、螢幕閱讀器、以及關掉 JavaScript 的讀者，看到的都是正確的數字。

讀者若在系統設定裡開啟「減少動態效果」，全部動畫會自動關閉，內容照常呈現。前庭功能障礙和偏頭痛患者對動態特別敏感，這個站不該讓他們不舒服。
