我是吳旻陽，神經內科醫師，在羅東博愛醫院看診。門診裡最常見的是頭痛與其他慢性疼痛、腦中風與腦血管疾病，還有失智症、巴金森氏症這類神經退化疾病。

如果你是要來看診的，這幾篇大概比履歷有用：神經內科門診的三種病人、頭痛不是只能吃止痛藥，還有頭痛看診前，先記下這五件事。

門診時間與掛號方式在這裡。

以下是完整履歷，年份和機構都列出來，給需要查證或轉介的人看。
